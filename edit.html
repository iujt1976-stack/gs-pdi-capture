EDIT INSPECTION

Pin units on today's board

Use this when coaches are done on the floor but Day’s Units / Daily Log is short. Does not invent records. Puts the serials back on today’s list and repairs a stomped lane if a Capture already exists.

Lane integrity (W2)

Audit only reads: it lists lanes where a Fail was cleared by a later Pass (A, legitimate before W2), where a Pass sits on a live defect (B), and where session history has marks that the lane summary lacks (C). It never restores anything. Heal all lanes rebuilds a lane summary from its saved sittings, only for lanes saved since W2, and only when the store lists a sitting the summary has not folded. Safe to run again. Run it after the release and at end of day.

Lane health (W3A)

A scan, not a live counter: it reads every lane in the date range and counts what is wrong. It changes nothing. The last finished scan is stored and shown below. A mark filed under its owning lane is not counted as missing.

Fails awaiting clear (W3A)

A Fail stays a Fail until an admin clears it here. Pick Pass or N/A, type the reason, press the button. The Fail line, its defect and the history are all updated together and the clear is logged with your reason. Run the health scan above to fill this list.

Restore damaged lanes (W3A)

Step 1 Dry run only reads: for each lane it lists every mark that would change (from, to), flags any Fail to non-Fail (apply refuses those), any Pass to N/A and any completion flip, and puts the counts on top. Restore PATCHES the lane summary: it sets the restored Fail lines and adds marks the whole unit lacks; it never rebuilds the lane, renames a key or changes any other mark. Step 2 Save the list: you approve exactly that list (it gets an id). Step 3 Apply writes only what the saved list says, only to lanes still as the dry run saw them. Sittings are never touched. The old summary is kept in an admin log. A Fail you restore can still be cleared: use "Fails awaiting clear" or the Edit tool, and the clear stands (a re-run of this list will not re-fail it). Units 0000 and 000001 are refused. Parity checks that the new rebuild gives the same result as W2 on every lane without a restore.

Add unit as Administratively Closed

Done in the plant, never hit four digital lanes. Lands on Daily Log and Day’s Units Cleared. Does not wipe lanes already in.

1. Load unit

Load a unit first. Every write needs a reason in the box below.

2. Lane status

Delete this lane

Junk sitting, not a wrong serial. Other lanes stay.

Reopen a force-close

Takes the admin close off. A stub with no marks is removed. A real sitting stays.

Name on this lane

Sets the inspector on every sitting in the lane. Does not move the record.

3. Force-close a lane

Closes a missing lane, an Add Inspection leftover, or a partial Capture so the unit can clear. Does not wipe marks already on the record.

4. Time

Exempt from target

Seat-eval only. Pulls this sitting out of the lane-time median (target is set in Ops Settings).

5. Merge fat-finger serial

Copies every lane and clears this serial. Not the one-lane move.

Move one lane

Moves only the lane you pick. Other lanes stay on this serial. Use this when Interior was typed on the wrong unit.

Batch close leftovers

Last 7 days still missing a lane. Officially done in the plant — close the missing / assist-only lanes. Real Capture lanes already in stay. Time on new stubs is voided.
